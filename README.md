# Projeto-Acolher-
O Acolhe+ é uma proposta de sistema de apoio à organização de informações e compromissos relacionados ao acompanhamento de crianças atípicas. O projeto foi concebido para o contexto de um curso Técnico em Informática, priorizando um escopo viável, uma interface simples e funcionalidades que possam ser implementadas e demonstradas pela equipe.
