# Projeto-Acolher+
Olá! Tudo bem? 

Somos estudantes do Curso Técnico de Informática (TI) no GRAU TÉCNICO e estamos desenvolvendo um projeto de aplicativo voltado ao apoio de famílias e cuidadores de pessoas neurodivergentes.

Nosso objetivo é criar um sistema que facilite a rotina de quem acompanha essas pessoas diariamente, auxiliando na organização de consultas, compromissos, atividades e demais cuidados necessários. O aplicativo contará com recursos para agendamento e gerenciamento de consultas, permitindo uma melhor organização entre familiares, cuidadores e profissionais que acompanham cada pessoa.

Para que possamos desenvolver uma solução que realmente atenda às necessidades do dia a dia, elaboramos um formulário com algumas perguntas. As respostas serão muito importantes para compreendermos as principais dificuldades enfrentadas pelas famílias e identificarmos recursos que possam tornar essa rotina mais prática e organizada.
