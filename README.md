# Acolher+

## Sobre o projeto

O Acolher+ é um projeto de desenvolvimento de um aplicativo voltado para auxiliar pessoas neurodivergentes, familiares e cuidadores na organização das informações relacionadas ao seu acompanhamento. A proposta surgiu da necessidade de reunir, em um único sistema, dados que muitas vezes ficam espalhados entre agendas, documentos, aplicativos de mensagens e outros meios.
O projeto busca oferecer uma solução tecnológica prática e acessível, com funcionalidades como agenda de consultas e terapias, lembretes, cadastro de profissionais, registro de atendimentos, organização de documentos e compartilhamento seguro de informações. Também prevê o acesso a conteúdos informativos e a uma rede de apoio com instituições e serviços úteis às famílias.
Desenvolvido no contexto do curso Técnico em Informática, o Acolher+ tem como objetivo demonstrar como a tecnologia pode contribuir para melhorar a organização da rotina familiar, facilitar o acesso às informações e tornar o acompanhamento das pessoas neurodivergentes mais organizado, sempre considerando a privacidade e a proteção dos dados.



## Problemas identificados 

Como desenvolver um sistema que facilite a organização das informações e dos compromissos relacionados ao acompanhamento de pessoas neurodivergentes, proporcionando maior praticidade aos usuários, familiares e cuidadores?
Principais problemas identificados: 
• informações espalhadas em diferentes meios; 
• dificuldade de controlar muitos compromissos e horários; 
• documentos e registros difíceis de localizar; 
• necessidade de acompanhar vários profissionais; 
• histórico de atendimentos sem organização centralizada; 
• necessidade de compartilhar informações sem perder o controle de acesso; 
• dificuldade de localizar instituições, serviços e conteúdos de apoio. 

## Objetivos 

Desenvolver um sistema que auxilie pessoas neurodivergentes, seus familiares e cuidadores  na organização e no gerenciamento de informações, compromissos e recursos relacionados ao acompanhamento  e ao bem-estar.

### Objetivos específicos 
• facilitar o controle de consultas e terapias; 
• centralizar informações importantes; 
• permitir o armazenamento organizado de documentos; 
• auxiliar no acompanhamento da rotina; 
• facilitar o acesso a informações e recursos de apoio; 
• permitir compartilhamento controlado com profissionais autorizados; 
• reduzir a necessidade de utilizar diferentes ferramentas para organizar essas informações. 

## Funcionalidades

O Acolher+ será organizado em módulos que auxiliarão pessoas neurodivergentes, seus familiares e cuidadores na organização de informações, compromissos e recursos relacionados ao acompanhamento e ao bem-estar.

| Módulo | Funcionalidades |
|---|---|
| Minhas informações | Cadastrar e consultar dados pessoais e informações relacionadas ao acompanhamento. |
| Agenda | Organizar e consultar consultas, terapias, reuniões, avaliações e outros compromissos. |
| Atendimentos | Registrar e consultar o histórico de atendimentos e a evolução do acompanhamento. |
| Documentos | Armazenar e organizar documentos pessoais e registros relacionados ao acompanhamento. |
| Profissionais | Cadastrar e consultar profissionais envolvidos no acompanhamento. |
| Compartilhamento | Controlar o acesso de profissionais autorizados às informações. |
| Conteúdos informativos | Disponibilizar artigos, guias, notícias e materiais informativos. |
| Rede de apoio | Consultar instituições, serviços, locais e contatos úteis. |
| Administração | Gerenciar usuários, conteúdos, instituições, configurações e segurança. |

## Tecnologias utilizadas

● Python: linguagem de programação utilizada no desenvolvimento do sistema.

● Flask: framework utilizado para desenvolver a aplicação web. 

● SQLite: banco de dados utilizado para armazenar as informações.

● HTML5 / CSS3: tecnologias utilizadas para estruturar e estilizar as páginas.

● Bootstrap 5: framework utilizado para auxiliar na criação de uma interface responsiva.

● Font Awesome: biblioteca de ícones utilizada na interface.

## Instalação

1. Baixe ou clone o repositório do projeto para o computador.

2. Certifique-se de que o Python esteja instalado.

3. Abra o terminal na pasta principal do projeto.

4. Instale o Flask executando o comando:

      *pip install flask*

5. Verifique se o arquivo database.db está na pasta principal do projeto, conforme a estrutura esperada pela aplicação

## Como executar

1. Abra o terminal na pasta principal do projeto.

2. Execute o comando:

       *python app.py*

3. Aguarde a inicialização da aplicação.

4. Abra o navegador e acesse o endereço informado no terminal. Caso a aplicação esteja utilizando a configuração padrão do Flask, o endereço geralmente será:

      *http://127.0.0.1:5000*
